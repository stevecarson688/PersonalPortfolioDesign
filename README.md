# Steve Carson - Portfolio

Portfolio personnel de Steve Carson, développeur Full Stack web et mobile, Delivery Manager et User Tester basé à Yaoundé, Cameroun.

## Contenu

- Présentation personnelle et parcours professionnel
- Expériences en développement web, mobile, ERP/Odoo et User Testing
- Compétences en automatisation, gestion de projet, développement et bases de données
- Formation et travaux de recherche
- Liens de contact, LinkedIn et GitHub

## Technologies

- HTML
- CSS
- JavaScript
- Responsive design
- Intersection Observer API

## Lancer le portfolio

Le projet est une page statique. Ouvrez simplement `index.html` dans un navigateur.

Pour un aperçu local avec un serveur statique, utilisez par exemple l'extension Live Server de VS Code.

## Fichiers principaux

- `index.html` : structure et contenu du portfolio
- `styles.css` : styles, responsive design et animations
- `script.js` : menu mobile, filtres, timeline et formulaire de contact
